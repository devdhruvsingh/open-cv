# Grain Counter using OpenCV

A simple computer vision project that counts rice grains or lentils from an image using Python and OpenCV.

## Features

- Count rice grains or lentils from an image.
- Detect individual grains using contour detection.
- Save an annotated output image.
- Lightweight and beginner-friendly.

## Tech Stack

- Python
- OpenCV
- NumPy
- Matplotlib
- Pytest
